# 松鼠世界资料工作台实施计划

## 1. 当前交付边界

本轮只交付资料工作台前端页面，不接入新的上传、解析、预览、OCR 或 WPS 服务。

- 已完成：松鼠世界主题页头、四个对称能力入口、统一文件选择、文件名/大小/类型的本地分类、处理路线和格式地图。
- 已移出资料页：原“简历上传”和“可信经历资料库”两个独立模块。
- 明确未实现：文件持久化、在线预览、OCR、WPS 在线编辑、版本回写和资料归档。
- 前端展示的“待处理”仅为当前浏览器内存状态，刷新后不保留，也不会把文件发送给后端。

## 2. 支持范围

| 分类 | 前端已列出的扩展名 | 后续处理方向 |
| --- | --- | --- |
| WPS 文字 | `.wps` `.doc` `.docx` `.rtf` | 预览、WPS 编辑、文本提取 |
| WPS 表格 | `.et` `.xls` `.xlsx` `.csv` | 表格预览、WPS 编辑 |
| WPS 演示 | `.dps` `.ppt` `.pptx` | 幻灯片预览、WPS 编辑 |
| PDF 与图片 | `.pdf` `.png` `.jpg` `.jpeg` `.webp` `.bmp` `.gif` | 原图/PDF 预览、OCR |
| 压缩包与源码 | `.zip` `.7z` `.7p` `.html` `.htm` `.py` `.md` `.txt` | 安全清单、纯文本预览 |
| 音视频 | `.mp3` `.mp4` `.mkv` | 元数据、播放器预览 |

`.7p` 按用户要求保留为前端入口，但它不是常见的标准压缩扩展名。后端开发前必须确认它是否代表 `.7z` 的别名或某个特定格式；确认前不得把它交给解压器。

## 3. 分阶段实现

### 阶段 A：安全上传与本地归档

1. 新增统一资料上传接口、资料记录、处理任务和状态字段。
2. 同时校验扩展名、真实 MIME、文件魔数、单文件大小、总大小和文件数量；拒绝双扩展名伪装。
3. 文件名改为服务端生成的安全名称，保留原始名称作为元数据；计算哈希用于去重与审计。
4. `.py`、`.html`、Markdown 和压缩包内容只作为资料读取，绝不执行；HTML 预览必须清洗脚本和危险标签。
5. ZIP/7Z 增加路径穿越、软链接、嵌套深度、解压后体积和文件数量限制，防止 Zip Slip 与解压炸弹。
6. 上传失败、处理中、可预览、需 OCR、可编辑和处理失败都返回明确状态，不吞掉错误。

### 阶段 B：在线预览

1. 图片和 PDF 使用只读预览；可提取文字的 PDF 同时展示文本层。
2. DOC/DOCX/WPS、XLS/XLSX/ET、PPT/PPTX/DPS 先生成只读预览副本，原件保持不变。
3. HTML 使用隔离沙箱和内容清洗；PY/MD/TXT 使用只读代码/文本查看器。
4. ZIP/7Z 只展示安全扫描后的文件清单，不直接执行或自动展开其中内容。
5. MP3/MP4/MKV 使用浏览器播放器；不支持的编码给出转码提示，不伪装成加载成功。

### 阶段 C：图片与 PDF OCR

1. 图片和扫描 PDF 创建逐页 OCR 任务，保存页码、置信度、识别文本和错误信息。
2. 页面采用“原图/原页 + OCR 文本”并排校对，低置信度片段突出显示。
3. 用户修订另存为新版本，不能覆盖原文件和原始 OCR 结果。
4. OCR 文本可搜索、导出，并能作为后续 Agent 证据；引用时保留文件、页码和区域定位。

### 阶段 D：WPS 编辑接入

1. 开发前确认编辑模式：本机 WPS 客户端打开，或 WPS 开放平台的网页编辑。两种方案分别实现适配器，不在页面中混为同一能力。
2. 若使用 WPS 开放平台，先完成账号、应用、回调域、授权范围和 SDK/API 可用性验证；密钥只存环境变量。
3. 每次编辑创建工作副本；保存回调必须校验签名、用户、资料 ID 和版本，避免覆盖并发修改。
4. 编辑完成后回写新版本、操作者、时间、来源版本和哈希，原件始终可恢复。
5. WPS 暂不支持的格式自动回退到只读预览或下载，不显示虚假的编辑按钮。

### 阶段 E：资料库、搜索与 Agent 引用

1. 增加资料卡片、标签、来源、版本、处理状态、最近使用时间和检索入口。
2. 资料卡按类型进入文档、图片、源码、压缩包和音视频分组，保持当前对称卡片布局。
3. Agent 只能引用完成解析且用户允许使用的资料；生成内容必须能回溯到文件和版本。
4. 删除前展示引用影响，优先使用可恢复删除；彻底删除时同步清理派生预览和 OCR 文本。

## 4. 验证与验收

- 单元测试：格式映射、大小限制、状态流转、文件名处理、版本冲突和错误提示。
- API 测试：上传、查询、预览、OCR、WPS 回调、权限与失败恢复。
- 安全测试：伪造 MIME、双扩展名、目录穿越、解压炸弹、危险 HTML、可执行源码和超大文件。
- 前端测试：loading、error、empty、处理中、已完成、失败与移动端布局。
- 端到端测试：上传到预览、OCR 校对、WPS 编辑回写、版本恢复和 Agent 引用。
- 人工验收：至少各验证一份 WPS 文字、表格、演示、PDF、图片、压缩包、源码、MP3、MP4 和 MKV；真实 WPS 编辑必须在目标 Windows/WPS 环境中验收。

只有对应阶段的自动化测试、全量测试、构建、静态检查和真实浏览器检查全部通过后，页面状态才能从“下一阶段接入”改为“可用”。

## 5. 推荐实施顺序

按 A → B → C → D → E 执行。安全上传和持久化是其他能力的共同前提；WPS 接入依赖外部账号与运行方式选择，应在只读预览和 OCR 链路稳定后再实现。
